# Instructions for contributors

## My Carz: continuing user approval and animation requirements

Before changing My Carz runtime, assets, shared integration, tests or documentation, read:

- `assets/my-carz-game-scripts/my-carz-game-details.md`
- `assets/my-carz-game-scripts/my-carz-game-progress.md`

Bring proposed changes/deletions to the user and obtain explicit approval first. A specific user-requested change authorizes that scope only. Preserve existing content, features and approved animations, including timings, sequencing, intensity, continuity and audio synchronization. General cleanup, smoothness, optimization or compatibility requests do not authorize collateral changes or suppressing effects.

Keep animations smooth and well sequenced. Update the progress document after every authorized feature/fix and report visual-verification limits. Do not silently weaken these requirements. My Carz media lives in `assets/my-carz-game-assets/`; scripts and tracking documents live in `assets/my-carz-game-scripts/`. Original Good Bad Ugly assets remain separate.

Rocketier has additional scoped instructions in `assets/rocket-game-scripts/AGENTS.md`.
My Carz startup/handoff instructions: `assets/my-carz-game-scripts/README.md`. Original source flow: `assets/my-carz-game-scripts/docs/Carz Game Flow.docx`; the tracking documents contain subsequent approved clarifications.
