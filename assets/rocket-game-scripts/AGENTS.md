# Repository instructions for AI agents

## Rocket'ier: mandatory user preservation instruction

Before changing Rocket'ier code, assets, cache integration, tests, or documentation, read the mandatory preservation rule at the top of:

- `assets/rocket-game-scripts/rocket-game-details.md`
- `assets/rocket-game-scripts/rocket-game-progress.md`

Do not remove existing Rocket'ier features, content, assets, or effects, or suppress, shorten, reduce, or replace approved animations without the user's explicit permission for that specific change. General cleanup, optimization, smoothness, accessibility, or compatibility requests do not authorize collateral removal. This includes reduced-motion branches and global near-zero animation durations. Preserve approved motion across browser/device settings unless a specific change is explicitly authorized.

Review changes for animation regressions, verify affected sequences, report verification limits, and update the progress file after each feature/fix. This continuing user instruction applies to future agents and context resets. Do not silently weaken or delete it. See the two linked documents for the complete rule and current behavior.
