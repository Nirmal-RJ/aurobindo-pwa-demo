# Wave Rider contributor rules

Read README.md, wave-rider-rules.md and wave-rider-progress.md before changes. Preserve approved client content, reference composition, timers, penalties and continuous effect sequence. Keep scripts/assets isolated. Do not alter other games, shared login or their assets. Do not shorten questions/explanations. Get explicit approval for collateral changes and deletion of supplied media. Record changes and validation after each fix. Match supplied image assets without distorting individual elements; check Edge/WebKit and small portrait screens. Animations must complete coherently, input must be gated during transitions, and backgrounding must not pause the question timer. No Git push/deployment unless explicitly requested. Report unavailable audio/demo media and physical-device limits honestly.
