# Instructions for contributors — See Saw

## Scope and Isolation

Before modifying See Saw runtime, assets, shared integration, tests, or documentation, read:

- `assets/see-saw-scripts/see-saw-rules.md`
- `assets/see-saw-scripts/see-saw-progress.md`
- `assets/see-saw-scripts/docs/SEE SAW.docx`

Bring proposed changes or deletions to the user and obtain explicit approval first. A specific user-requested change authorizes that scope only. Preserve existing content, features, approved animations, timings, audio crossfades, and visual similarity to the supplied reference images (`page-1-reference.webp` through `page-12-reference.webp`).

- All See Saw visual and audio media live in `assets/see-saw-assets/`.
- All See Saw runtime scripts, styles, HTML, service worker, and documentation live in `assets/see-saw-scripts/`.
- Do not modify any other game in the repository or alter shared authentication/review backend logic.
- Update `assets/see-saw-scripts/see-saw-progress.md` after every authorized feature or fix and report visual-verification limits.
