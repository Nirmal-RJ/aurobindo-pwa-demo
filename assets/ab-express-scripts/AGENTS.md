# AB Express contributor instructions

Read README.md, ab-express-game-details.md, ab-express-game-rules.md and ab-express-game-progress.md before changes.

Keep media in ../ab-express-assets and code/docs here. User-approved clarifications override the source DOCX and baked-in artwork. Preserve approved content and animations; a scoped change does not authorize collateral redesign or suppressed effects.

Update progress after each feature/fix. Run assets:ab-express when assets change, check:ab-express and test:ab-express for runtime changes. Check affected browser sequences and report physical-device limits honestly. Keep HTML URL versions and scoped worker version aligned. Do not modify other games as part of AB Express work.

Client instruction copy is immutable: render config.steps verbatim in practice, challenge and comparison. No shortened aliases or paraphrases without explicitly approved replacement copy.
